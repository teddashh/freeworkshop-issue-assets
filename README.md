# freeworkshop-issue-assets

Images (screenshots) attached to GitHub issues that the 自由工坊 Discord helper bot files on behalf of community members, after the reporter or an admin confirms the draft in Discord. Discord CDN attachment links expire, so the images are committed here and linked from the issue.

Layout: `<owner>/<repo>/<YYYY-MM>/<draft-id>-<n>.<ext>`. Metadata (EXIF) is stripped before upload.

To remove an image (e.g. it shows personal info), delete the file here and edit the issue.
